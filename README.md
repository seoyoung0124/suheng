[프로젝트 소개]

Daily Planner는 수행평가, 시험, 개인 일정 등을 한 곳에 기록하고, 하루 단위로 완료를 체크하고, 주간/월간 통계로 지난 날을 돌아볼 수 있는 학생용 일정 관리 앱이다.

<해결하려는 문제>
수행평가, 시험, 개인 일정이 달력 앱, 메모 등에 흩어져 있어 한눈에 보기 어렵고, 못 끝낸 일정이 쌓여도 알아차리기 힘든 점

<대상 사용자>
수행평가와 시험 일정, 개인 일정 등을 관리해야 하는 학생

<이 문제가 발생하는 상황·배경>
학기 중에는 과목마다 수행평가 날짜가 다르고 동아리, 개인 일정까지 겹쳐서 일정을 놓치기 쉽다. 일정을 따로 관리하지 않으면 중요한 일정을 놓치는 일이 발생한다.

<기존 방식과의 차이점>
일반 캘린더 앱은 일정 기록 중심이지만, 이 앱은 한 번 입력한 일정은 캘린더, 플래너, 통계에 연동되고, 중요도와 카테고리 지정, 완료 체크, 못 끝낸 일정 이월, 일정 검색, 주간/월간 통계를 한 앱에서 모두 이용할 수 있다.



[사용법]

1. 회원가입 / 로그인: 처음이면 '회원가입' 탭에서 이메일과 비밀번호로 계정을 만든 뒤(회원가입 버튼을 누르면 그 이메일로 인증 메일이 감. 인증 메일의 주소 클릭) '로그인' 탭에서 로그인한다.

2. 일정 추가/수정/삭제/완료: 로그인 후 첫화면인 Calendar에서 날짜 칸을 누르면 일정 추가 팝업창이 뜬다. 제목과 자세한 설명, 중요도, 카테고리를 입력하고 저장한다. 달력의 일정을 누르면 달력 아래에 일정 정보가 나오며, 수정, 삭제, 완료를 할 수 있다.

3. 일별 일정 확인: My Planner에서 일별 일정을 확인하고, 끝낸 일정을 눌러 완료로 바꿀 수 있다. 지난 미완료 일정은 원하는 날로 이월시킬 수 있다.

4. 일정 통계: Stats에서 주간/월간 일정의 완료율과 카테고리별 일정을 확인한다.

5. 검색: Search에서 단어를 입력해 지난 일정이나 다가오는 일정을 찾고, 해당 날짜로 이동한다.

6. 테마 변경: Settings에서 화이트·블랙·파스텔 테마 중에서 고른다.

7. 로그아웃: 왼쪽 메뉴 하단의 로그아웃 버튼이나, settings에서 로그아웃 버튼을 누르면 처음 회원가입/로그인 화면으로 이동한다.
